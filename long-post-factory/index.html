📖 Long Post Factory

1 · Build & copy the prompt

Builds a prompt entirely on this page — no master-prompt file is loaded, which keeps the prompt short. It casts the AI as a veteran exam-faculty teacher for whichever exam you type (built-in personas for CTET / BPSC TRE / DSSSB TGT & PRT / UPTET / UP TGT / KVS / NVS / PGT / PRT — any other exam name still works, using a generic-but-real persona built from the name), and demands a full 6,000–8,000 words every run — a hard gate in the prompt, not a suggestion. The AI writes plain content inside {* type: title *} ... {* END *} blocks instead of hand-written styled HTML — far fewer output tokens, so it's less likely to run out mid-article. On mobile, expect the AI's reply to land in several messages given the length — that's normal, see Step 2.

Key terms, definitions, and technical labels always stay in English regardless of this split — this only controls the explanations/tricks/teacher-talk prose.

📱 Copy the prompt in parts (opens automatically after building — use this on mobile)

Mobile keyboards (Gboard/Samsung/SwiftKey clipboard) and mobile browsers silently truncate a single copy past roughly 8,000–10,000 characters, so the prompt is split into only as many parts as it actually needs to stay under that per-part. Tap "Build prompt" above first, then use these buttons in order — paste each one as its own message in the SAME chat before sending the next. Tell the AI to wait until you say "generation config: go" if it starts replying early. On a PC, skip this and use "Copy whole prompt" instead.

🔍 Audit already-published notes (retroactive scorecard)

Runs every file already in published-long-posts/ + pending-long-posts/ through the same validator used in Step 3 — no generation involved, read-only, never modifies anything.

2 · Paste the AI's reply

Paste the whole reply from DeepSeek/ChatGPT/Claude. The parser reads the machine-readable markers first, and falls back to reading the visible SEO panel + HTML if a model ignored them — nothing is ever a dead end. This prompt asks for 6,000–8,000 words every time, so on a phone the AI app itself will very likely split its answer across several messages — that's expected, not an error. Paste each chunk here as it arrives, tick "This is a continuation," and tap Parse again after every chunk; the last chunk should end with the <<<END_PUBLISHER_NOTES>>> marker.
